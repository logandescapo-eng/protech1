The Problem
"Finding a trusted, verified professional for home or business services remains a fragmented, unreliable, and often risky process for millions of people worldwide."
😰
For Clients
No reliable way to verify worker credentials, compare pricing, or guarantee service quality before booking.
💼
For Workers
Limited visibility beyond word-of-mouth, no digital presence, difficulty managing schedule and earning consistent income.
🌐
The Gap
No accessible local platform combining verification, booking, payment, and reviews in a single trusted marketplace.
💡 ProTech Solution
A trusted full-stack web marketplace connecting verified professionals with clients through transparent reviews, streamlined booking, and secure authentication.

System Architecture
Three-tier architecture separating presentation, logic, and data concerns for maintainability and scalability.
PRESENTATION TIER
HTML5 + CSS3 + JavaScript
landing.html | auth.html | dashboards
⬇ HTTP POST / GET
LOGIC TIER
PHP 7.4+
login_handler.php | auth_functions.php
⬇ MySQLi Queries
DATA TIER
MySQL — protech_db
12 tables | InnoDB | UTF-8
📂 Request Flow
1

Browser Request

User visits page via http://localhost/protech/

2

Form Submission

POST data sent to PHP handler

3

Validation & Query

PHP sanitizes input, runs prepared SQL

4

Session Created

User data stored in secure PHP session

5

Role-Based Redirect

Directed to user or worker dashboard

Authentication System
🔐 Three-Tab System
Tab 1 — Login
Email + Password fields, remember me, forgot password, POST to login_handler.php
Tab 2 — User Signup
Name, Email, Phone, Password → user_signup_handler.php → users table (user_type='user')
Tab 3 — Worker Signup
+ Service Area, Skills, Experience → worker_signup_handler.php → users + workers tables
🎓 Demo Mode
Quick access buttons bypass auth for academic presentations. Demo badge shown on dashboards.
